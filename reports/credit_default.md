# Credit-default sensitivity target (D022)

Generated by `python -m climrisk.features.credit_default`. Each D004 default is followed for 12 months after its first default month D. Temporary episode: no loss exit or REO, and current at D+12 or paid off within the follow-up. Everything else stays a default. Eligible loans only (window end + follow-up <= performance cutoff), the same rule for every loan.
